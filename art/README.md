# Art

Original characters for the child mode. No third-party character, brand or logo.

## Characters (2026-11-12)

Two characters, chosen by the therapist per child: a **boy** and a **girl**, about 8 years old.

| File | What |
|---|---|
| `concepts/boy-girl-v1.png` | Approved concept: both characters, front view (1536x1024) |
| `characters/boy-sheet.png` | Boy model sheet: front, 3/4, side, back; hands (palm, back, pointing, cup grasp); 5 expressions (calm, talking, helper look, celebrating, encouraging) |
| `characters/girl-sheet.png` | Girl model sheet, same layout; ponytail kept behind the neck so shoulders stay visible for dressing steps |

**Tool:** ChatGPT image generation (author's personal ChatGPT Plus account), driven through the browser. Every later image uses these sheets as the reference so the characters stay identical.

**Style rules:** premium 3D-lite cartoon, soft rounded shapes, gentle light, big kind eyes, calm smile; child-mode palette from DESIGN.md: sage `#5E9C8A`, sky `#7FA7C9`, lavender `#B9A6D3`, off-white background `#F6F4EE`; no red or orange, no text, no busy patterns.

Style: premium modern 3D-lite cartoon like a high-end animated feature, soft rounded shapes, gentle soft lighting, big kind expressive eyes with a calm friendly smile, clean simple outlines, no tiny details, calm and soothing, not hyperactive. Palette limited and calm; absolutely no red or orange, no busy patterns, no text, no logos, no brands, not resembling any existing character. Plain warm off-white background (#F6F4EE), soft ground shadow. Landscape 3:2, both characters same scale, centered, generous spacing."
