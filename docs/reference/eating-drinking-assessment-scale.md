# Functional Motor Skills Assessment Scale — Eating and Drinking Skills

> I have kept the **Score** and **Performance** columns empty as in the original form, so that they can be used to fill in the assessment.

## First: Eating skill
### 1. Eating a sandwich

| Step No. | Step | Functional domain | Functional sub-skills | Score | Performance |
|---:|---|---|---|:---:|:---:|
| 1 | Look at the sandwich | Visual-motor coordination | Directing gaze, visually locating the sandwich |  |  |
| 2 | Go to the eating place | Motor planning + Motor coordination | Identifying the place, organizing movement to reach it |  |  |
| 3 | Sit on the chair in a suitable position | Motor planning + Range of motion | Organizing the transition to sitting, moving the body's joints |  |  |
| 4 | Put the sandwich in front of you | Hand skills + Motor planning | Carrying the sandwich, determining where to place it, release |  |  |
| 5 | Reach your hand toward the sandwich | Range of motion + Visual-motor coordination | Extending the shoulder and elbow, directing the hand toward the target |  |  |
| 6 | Hold the sandwich in a way that suits your motor abilities | Hand skills | Palmar grasp, controlling grip pressure, stabilizing the food |  |  |
| 7 | Bring the sandwich close to your mouth | Visual-motor coordination + Range of motion | Directing the hand toward the mouth, coordinating hand and eye movement |  |  |
| 8 | Open your mouth | Range of motion | Opening the jaw and moving the mouth muscles |  |  |
| 9 | Take a small bite of the sandwich | Motor coordination | Coordination between hand and mouth movement, controlling the size of the bite |  |  |
| 10 | Chew the food well | Motor coordination | Coordinating jaw movement, lateral and alternating chewing |  |  |
| 11 | Swallow the food before taking another bite | Motor planning + Motor coordination | Organizing the eating sequence, coordinating the swallowing process |  |  |
| 12 | Repeat the steps until you finish eating the sandwich | Motor planning + Motor coordination | Remembering the sequence of steps, repeating the movement pattern |  |  |
