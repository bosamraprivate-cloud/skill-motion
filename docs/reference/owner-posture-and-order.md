# Posture and test order (project owners, 2026-11-14)

> Received from the project owners on 2026-11-14 (Arabic message), recorded here in English. It is a source for **staging** (how the child is positioned and in which order dressing tasks run). It adds no assessment steps.

## Seated skills

- **Dressing and undressing:** socks (taking off and putting on); shoes (taking off and putting on).
- **Eating:** sandwich, spoon, fork.
- **Drinking:** bottle, cup, straw.

## Standing skills

- **Dressing and undressing:** jacket (taking off and putting on); T-shirt (taking off and putting on); shirt (taking off and putting on).
- **Trousers (taking off and putting on):** standing; if the child cannot, they may take off and put on the trousers while seated.
- **Personal hygiene:** handwashing; brushing teeth.

## Order

- For each garment the child is first tested on **taking off** the garment they are wearing, then on **putting it back on**.

## Gap

- Taking-off steps exist in the sources only for the jacket (`dressing-assessment-scale.md` §1.2). Taking off the T-shirt, shirt, trousers, socks and shoes has no step table yet; it needs the owners' step list before it can be added (never invented).
