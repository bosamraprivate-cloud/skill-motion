# Scale for Assessing Functional Motor Skills — Personal Hygiene Skills

> The **Score** and **Performance** columns were kept empty as in the original form, to be used for filling in the assessment.

## Third: Personal hygiene skill
### 1. Handwashing

| Step No. | Step | Functional domain | Functional sub-skills | Score | Performance |
|---:|---|---|---|:---:|:---:|
| 1 | Look at the sink | Visual-motor coordination | Visually locating the sink |  |  |
| 2 | Go to the sink | Motor planning + Motor coordination | Identifying the place, organising the movement to reach it |  |  |
| 3 | Turn on the tap | Hand skills + Range of motion | Grasping the tap handle, turning it, moving the wrist and fingers |  |  |
| 4 | Wet your hands with water | Motor coordination + Range of motion | Placing the hands under the water, moving the hands and fingers |  |  |
| 5 | Get the soap | Motor planning + Hand skills | Locating the soap, reaching it, grasping it |  |  |
| 6 | Put soap on your hands | Hand skills + Motor coordination | Holding the soap, transferring it, controlling the hand movement |  |  |
| 7 | Rub your palms together | Motor coordination + Hand skills | Bilateral coordination, reciprocal movement of the hands, rubbing the palms against each other |  |  |
| 8 | Rub between your fingers | Hand skills + Motor coordination | Spreading the fingers, inserting the fingers of one hand between the fingers of the other, bilateral coordination |  |  |
| 9 | Rub the backs of your hands and around your nails | Hand skills + Motor coordination | Moving the fingers, using both hands together, controlling the hand movement |  |  |
| 10 | Rinse your hands with water | Motor coordination + Range of motion | Moving the hands under the water, rotating the hands and moving the wrist |  |  |
| 11 | Turn off the tap | Hand skills + Range of motion | Grasping the handle, turning it, controlling the movement of the fingers and wrist |  |  |
| 12 | Get the towel | Motor planning + Hand skills | Locating the towel, reaching it, grasping it |  |  |
| 13 | Dry your hands well | Hand skills + Motor coordination | Holding the towel, moving it over the palms, the backs of the hands and between the fingers |  |  |

### 2. Toothbrushing

| Step No. | Step | Functional domain | Functional sub-skills | Score | Performance |
|---:|---|---|---|:---:|:---:|
| 1 | Look at the toothbrush and the toothpaste | Visual-motor coordination | Locating the tools, visually discriminating between them |  |  |
| 2 | Get the toothbrush and the toothpaste | Motor planning + Hand skills | Identifying the required tools, reaching them, grasping and carrying |  |  |
| 3 | Open the toothpaste cap | Hand skills + Motor coordination | Precision grasp, turning the cap, using both hands together when needed |  |  |
| 4 | Put a small dot of toothpaste on the brush | Hand skills + Visual-motor coordination | Controlling finger pressure, directing the toothpaste nozzle, adjusting the amount of toothpaste |  |  |
| 5 | Hold the brush well | Hand skills | Functional grasp, stabilising the brush, finger control |  |  |
| 6 | Brush the front teeth | Motor planning + Motor coordination | Locating the teeth, directing the brush, organising the hand movement |  |  |
| 7 | Brush the back teeth | Motor planning + Range of motion + Motor coordination | Locating the back teeth, directing the brush inside the mouth, moving the wrist and arm |  |  |
| 8 | Brush your teeth from the inside | Motor planning + Motor coordination | Changing the brush direction, organising the movement path, controlling the hand movement |  |  |
| 9 | Brush the surface you chew food on | Motor planning + Visual-motor coordination | Locating the tooth surface, directing the brush to the required place |  |  |
| 10 | Finish brushing your teeth gently | Motor planning + Motor coordination | Organising the cleaning sequence, changing the brush direction, repeating the movement |  |  |
| 11 | Spit the toothpaste into the sink | Motor planning + Motor coordination | Directing the mouth towards the sink, coordinating the movement of the mouth muscles |  |  |
| 12 | Rinse your mouth and spit out the water if you can do so safely | Motor coordination | Coordinating the movement of the lips, tongue and cheeks, controlling rinsing and spitting |  |  |
| 13 | Rinse the brush with water | Hand skills + Motor coordination | Grasping the brush, moving it under the water, rotating it to clean the bristles |  |  |
| 14 | Return the brush and the toothpaste to their place | Motor planning + Hand skills + Visual-motor coordination | Locating the tools' place, carrying them, directing them to the place, releasing |  |  |
