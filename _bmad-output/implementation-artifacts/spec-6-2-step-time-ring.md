## Intent (owner approved 2026-11-14)

**Problem:** The attempt window uses hidden fixed rules (still after 20 s, hard cap 45 s) for every step. The owner wants a visible, game-like timer per step, sized by difficulty, with effects — without stressing autistic children.

**Approach:**
1. **Per-step time in the catalogue:** new `tools/catalog-builder/step_timing.json` = per-task default seconds + optional per-step overrides; `build_catalog.py` validates (every task has a default, overrides only for known step IDs, 5–60 s) and emits `"timeSec"` on every step in `assessment.json`. Draft values (pending owner review, recorded in `docs/reference/step-timing-draft.md`): steps whose English text starts with "Look"/"Identifies"/"Locate" = 10 s; eating/drinking default 15 s (drink/sip/chew/swallow steps 20 s); handwash default 15 s (rubbing steps 20 s); teeth default 15 s (brushing steps 25 s); dressing default 20 s (inserting arms/head/feet and fastening steps 30 s). Schema + pytest.
2. **Runner:** the attempt window closes at the step's `timeSec` (TIMEOUT) instead of the fixed 45 s; keep the still rule only as `still after max(timeSec, 20 s)`? No — remove STILL closing when a step has `timeSec` (the ring is the single clock); old catalogues without `timeSec` keep the current rules. Bump `WindowRules.RULES_VERSION`. A timeout is never a failure: same as today's TIMEOUT handling (verdict from evidence; no evidence → cannot_tell → retry at the next prompt level with the demonstration).
3. **Time ring (child step screen):** a calm circular ring around the character/step area that fills clockwise (RTL-aware) in sage over `timeSec`, no digits, no ticking sound. Last 3 s: gentle pulse only when the child's effect level is FULL (CALM: static). Done before the end: a small sparkle on the ring (FULL) / soft glow (CALM), plus the normal star. Time up: no negative sound/colour; the side character plays `encourage` and the existing help path continues. The ring pauses while instruction audio plays, while adult-paused, and while the screen is inactive.
4. **Per-child switch:** `showTimeRing` on the child (default true), edited in the child form ("Show time ring"); Room migration 7→8 + schema 8.json + migration test (unit `MigrationSqlTest` and androidTest `MigrationTest` 7→8). When off, the ring is hidden but the step time still closes the window.
5. **Docs:** child-flow.md, therapist-flow.md, EXPERIENCE.md.

## Boundaries

**Always:** doubt is never failure; colour never alone; RTL; Western digits in therapist UI; strings ar/en; unit tests (timing parse, window close at timeSec, ring state machine pause/resume, effect level behaviour, migration). Kover ≥ thresholds.
**Never:** no countdown digits, no alarm/ticking sound, no speed bonus stars, no hard-coded step IDs or seconds in Kotlin (except fallback constants for old catalogues). Coordinator runs the full Gradle gate.
